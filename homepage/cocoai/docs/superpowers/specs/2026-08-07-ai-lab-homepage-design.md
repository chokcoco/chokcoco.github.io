# 恬齐网络 AI 思维实验室首页改造设计

## 目标

将 `index.art` 从单一跳转页改造成“实验室杂志式”首页：保留现有波浪 SVG 的流动感，补足可信的品牌表达、课程入口和学习方向，同时不修改课程源文件或原有页面信息。

## 视觉方向

- 受众：寻找 AI 工程、智能体和知识系统学习路径的中文学习者。
- 气质：克制、探索感、可信，不采用常见的紫色 AI 渐变或重度玻璃卡片。
- 配色：深墨绿黑为底，灰白文字，电光青为唯一强调色。
- 动效：保留并弱化原有 SVG 波浪；为导航、链接和课程卡增加轻量 hover 与键盘焦点状态；尊重 `prefers-reduced-motion`。

## 信息架构

1. Header：站点名“恬齐网络AI思维实验室”，4 个锚点 TAB：实验室、学习路径、课程、关于。
2. 实验室首屏：定位文案、一个课程入口、一个阅读实验室说明入口，以及由编号和关键词组成的简短信息块。现有波浪 SVG 作为背景层保留。
3. 学习路径：用三段非卡片化内容呈现从基础、系统到工程实践的学习方向。
4. 课程：从 `../ai-course-studio/courses/` 聚合拥有 `index.html` 的课程；明确排除 `fbs-fullstack-landing`。每张卡展示课程标题、摘要、章节数量或时长，并链接到该课程的 `index.html`。
5. 关于：说明实验室围绕 AI 思维、可验证工程与持续学习组织内容。
6. Footer：保留版权信息并提供不含编号的备案留白位，日后由站点维护者补充真实备案号和工信部链接。

## 课程聚合规则

- 初始展示当前目录中已具备入口页的课程。
- 不展示 `fbs-fullstack-landing`。
- 将课程聚合信息直接写入首页 HTML，避免依赖浏览器读取本地目录。
- 课程新增后可复制一张课程条目并替换标题、描述、链接与元信息；页面的响应式网格自动适配。

## 实现与响应式

- 仅修改 `index.art`，样式写在其现有 `<style>` 中，不创建运行时依赖。
- 移除页面级 `overflow: hidden`，使内容可滚动；保留背景波浪为固定/绝对背景。
- 桌面端课程区使用不对称 CSS Grid；移动端切换为单列，TAB 横向滚动，文案与操作区不重叠。
- 链接采用相对部署路径，假定站点会把课程目录发布到 `/courses/<slug>/`；若实际部署路径不同，只需调整每张卡的 `href`。

## 验证

- 用 HTML 解析检查结构完整性和主要锚点/课程链接。
- 在桌面与移动视口检查文字换行、导航、课程网格、页脚与滚动。
- 检查无效的空链接、重复 ID、不可见焦点和动效降级。
